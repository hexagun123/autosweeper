## Instructions
Just get the file and do some configuration, as you probabily won't have the same screen as mine.
1. Go to the start of the file, there should be some global variables there, change the two constant SCREEN_X and SCREEN_Y.
2. Check if the entire minesweeper screen fits when you press F2, you can also check if it works by clicking one of the tiles and see the output within the command line. (-1 stands for not opened, 0 stands for opened, 9 stands for flags, rest should be intuitive)
